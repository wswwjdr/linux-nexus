# Linux Nexus

**用 Windows 图形界面管理 Linux 服务器文件，并直接执行远端 SSH 命令。**

Linux Nexus 将文件列表、预览、搜索、上传下载、复制移动、归档和 SSH 终端放在同一个桌面应用中。文件管理器是服务器命令的图形化操作界面：远端文件复制、移动、删除和解压由服务器运行，不会把文件内容经 Windows 中转。

## 主要能力

- 多标签 SSH 文件会话和终端会话，可同时连接多台服务器。
- 远端目录浏览、属性读取、文件名及文本搜索。
- 文本、Markdown、图片、PDF、音频、视频和日志预览；媒体按需读取服务器字节范围。
- 使用服务器 `cp`、`mv`、`rm`、`mkdir`、`tar` 等命令执行文件操作。
- 上传通过 SSH stdin 发送文件字节，下载通过 SSH stdout 接收；远端复制和移动只在服务器内执行。
- 远端脚本执行、命令别名管理和性能监控。

## 运行

开发运行需要 Windows、Node.js 22.12+ 和 npm：

```powershell
npm install
npm run dev
```

生成 x64 NSIS 安装包：

```powershell
npm run dist:win
```

## 服务器要求

正式支持 Ubuntu、Debian、CentOS Stream 和 RHEL 8+。文件会话通过 SSH 命令通道调用 Bash、GNU coreutils、GNU findutils、grep、tar、sha256sum、dd、tail、stat 和 mktemp；不会安装常驻辅助程序。归档格式需要的 unzip、gzip、bzip2、xz 或 zstd 在使用时单独检测；缺少依赖时可确认由应用调用 apt、dnf 或 yum 安装。

首次连接会显示 SSH 主机指纹供核对。SSH 密码由 Windows 凭据能力加密保存。文件会话启动后会检查服务器系统和基础命令能力。

## 操作规则

需要选择策略的远端操作遵循“服务器预检、图形确认、最终服务器命令”。复制和移动由服务器执行；文件夹复制递归并保留权限与修改时间，不伪造所有者。上传和下载只传输完成任务所需的字节流。文本保存先比较 SHA-256；远端内容发生变化时，可重新加载或明确选择覆盖。

归档使用服务器已有的 Linux 命令在私有临时目录中展开，再由服务器命令合并到目标目录。归档安全边界遵循服务器原生命令，不提供自定义归档解析器。

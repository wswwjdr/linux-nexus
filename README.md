# Linux Nexus

简体中文 | [English](README.en.md)

**用 Windows 图形界面管理 Linux 服务器文件，并直接执行远端 SSH 命令。**

## 主要能力

- 文件管理：目录浏览、搜索、上传下载、复制移动、重命名、删除和解压。
- SSH 会话：多标签文件管理与终端，同时连接多台服务器。
- 预览与工具：文本、Markdown、图片、PDF、音视频和日志预览，以及远端脚本执行、命令别名和性能监控。

Markdown 提供只读排版、目录、代码高亮与复制，并显示服务器及网络图片；图片支持缩放、拖拽、旋转和翻转；音视频支持快捷键，视频提供全屏和长按临时倍速。操作与限制见[文件预览](docs/文件预览.md)。

## 核心设计原则

文件管理器通过图形界面收集参数，经 SSH 命令通道调用服务器原生命令，远端复制和移动的文件内容不经 Windows 中转。
多步操作先记录已知信息，待交互补齐参数后再生成命令并通过 SSH 执行。

## 界面语言

支持简体中文和英文，语言资源随应用分发，无需联网。首次启动默认跟随系统：中文系统使用简体中文，其余语言使用英文。
在应用设置的「语言」中选择「跟随系统」「简体中文」或「English」，切换立即生效并自动保存，不会中断连接、传输或预览。
文件名、命令、终端输出和远端文件内容保持原文；Windows 原生控件遵循系统语言。

## 运行

开发运行需要 Windows、Node.js 22.12+ 和 npm：

```powershell
npm install
npm run dev
```

开发服务固定使用 `50001` 端口；端口被占用时启动会报错，不会自动切换端口。

生成 x64 NSIS 安装包：

```powershell
npm run dist:win
```

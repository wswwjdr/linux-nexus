# Linux Nexus

用于通过 SSH/SFTP 浏览和管理 Ubuntu 服务器文件的 Windows 桌面客户端。

## 功能

- 保存多个服务器连接，并安全保存 SSH 密码。
- 未连接时在主区域查看所有已保存的服务器，最近成功连接的排在前面；可从列表连接、添加、编辑或删除服务器。
- 浏览远程目录，默认从根目录 `/` 开始。
- 在设置中选择默认文件视图，保存后立即应用并在下次启动时继续使用；浏览时也可临时切换图标视图与详细信息视图。详细视图显示名称、大小、修改时间和权限，悬停名称可查看完整文件名。
- 上传多个文件或递归上传文件夹，也可下载文件和递归下载文件夹；传输过程中可以取消。
- 右键菜单支持下载、复制远端绝对路径或删除，文件还可预览。删除前会确认，删除文件夹时会递归删除其中内容；服务器根目录不可删除。
- 预览 JPG、JPEG、PNG、GIF、TXT、SH、MP3 和 MP4 文件。图片可用鼠标滚轮缩放；视频支持拖动进度条，聚焦播放器后可用左右方向键以 5 秒为单位跳转。
- 在设置中分别调整文本、图片、音频和视频的预览大小上限，范围为 1 至 1024 MiB；设置会保存并在重启后保留。
- 首次连接时校验服务器主机指纹，并记住已确认的指纹。
- 同一时间只允许一个应用实例运行；再次启动会显示并聚焦已有窗口。切换服务器时会关闭当前连接。

## 文件操作

未连接时，主区域显示所有已保存的服务器，最近成功连接的排在前面。点击服务器可连接，也可在列表中添加、编辑或删除配置。连接后列表隐藏；断开连接后可返回列表选择其他服务器。

选择服务器并进入目录后，可通过路径栏切换图标视图或详细信息视图。右键文件或文件夹打开操作菜单；“复制绝对路径”复制以 `/` 开头的远端 POSIX 路径。

上传和下载的进度会显示在窗口底部的传输区域。进行中的任务可取消；取消会停止后续文件并清理未完成的临时文件，取消前已完整传输的文件会保留。已完成或已取消的状态记录可以关闭隐藏。

图片滚轮缩放范围为 25% 至 400%，以鼠标指针位置为缩放锚点。MP4 视频可通过原生进度条跳转；播放器获得焦点后，按左右方向键可前进或后退 5 秒。

## 文件预览

预览上限按文件类型单独设置，默认值如下：

| 类型 | 默认上限 |
| --- | ---: |
| 文本 | 5 MiB |
| 图片 | 100 MiB |
| 音频 | 100 MiB |
| 视频 | 100 MiB |

设置入口位于主窗口顶部。每项上限必须是 1 至 1024 MiB 之间的整数。预览开始前会根据远端文件大小检查上限；读取期间也会持续限制数据量。超过上限的文件不会生成可访问的预览内容，请下载后查看。文本内容在内存中读取，图片、音频和视频使用临时文件；关闭预览或退出应用后会清理预览资源。

支持的格式及显示方式见[文件预览说明](docs/文件预览.md)。

## 配置与连接安全

连接配置、加密后的 SSH 密码和已确认的主机指纹保存在 Electron 当前用户的应用数据目录中的 `servers.json`；预览上限保存在同目录的 `settings.json`。默认视图和最近连接信息保存在本机应用偏好中。密码使用 Electron `safeStorage` 加密。

应用启动时会校验配置文件。若 JSON 无法解析或数据结构无效，应用会显示出错文件的路径并退出，不会自动重置或覆盖该文件。保存配置时使用同目录临时文件和原子替换。

## 开发

需要 Node.js 22.12 或更新版本，以及 npm。

```powershell
npm install
npm run dev
```

## Windows 安装包

```powershell
npm run dist:win
```

x64 NSIS 安装包生成在 `release/` 目录。

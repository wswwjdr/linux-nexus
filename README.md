# Linux Nexus

**用 Windows 图形界面管理 Linux 服务器文件，并直接执行远端 SSH 命令。**

Linux Nexus 将文件列表、预览、搜索、上传下载、复制移动、归档和 SSH 终端放在同一个桌面应用中。文件管理器是服务器命令的图形化操作界面：远端文件复制、移动、删除和解压由服务器运行，不会把文件内容经 Windows 中转。

## 核心设计原则

**文件管理器的首要职责是免去用户手敲命令；远端文件操作的实际实现统一通过 SSH 命令通道调用服务器原生命令完成。** 文件列表、右键菜单、文件选择器和弹窗负责收集操作参数、编排命令及展示结果，用户无需手输命令。上传和下载通过 SSH stdin / stdout 传输必要的文件字节，不使用 SFTP 子系统。

**需要多步交互才能确定完整参数的操作，统一遵循：先记录已知信息 → 后续交互补齐参数 → 生成命令 → 通过 SSH 执行。** 参数尚未补齐时，只保存操作意图和已知参数，不提前执行该操作对应的远端修改命令。是否显示确认弹窗由具体工作流决定；生成命令本身不要求额外确认，也不要求用户查看命令。这一原则适用于现有及后续新增的同类工作流，例如：

- 复制／剪切：先记录源路径、操作模式和所属服务器；粘贴时补齐目标目录及处理策略，再生成并执行 `cp` / `mv` 命令。
- 拖放移动：开始拖动时记录来源，放到目标文件夹时补齐目标，再生成并执行 `mv` 命令。
- 解压到指定目录：先记录压缩包和处理策略，在远端目录选择器中确定目标后，再生成并执行解压命令。
- 上传文件／文件夹：记录远端目标，选择本机来源并收集文件清单，确定处理策略后执行上传及服务器写入命令。

## 主要能力

- 多标签 SSH 文件会话和终端会话，可同时连接多台服务器。
- 远端目录浏览、属性读取、文件名及文本搜索。
- 文本、Markdown、图片、PDF、音频、视频和日志预览；媒体按需读取服务器字节范围。
- 使用服务器 `cp`、`mv`、`rm`、`mkdir`、`tar` 等命令执行文件操作。
- 上传通过 SSH stdin 发送文件字节，下载通过 SSH stdout 接收；远端复制和移动只在服务器内执行。
- 远端脚本执行、命令别名管理和性能监控。

## 运行

开发运行需要 Windows、Node.js 22.12+ 和 npm：

```powershell
npm install
npm run dev
```

生成 x64 NSIS 安装包：

```powershell
npm run dist:win
```

## 服务器要求

正式支持 Ubuntu、Debian、CentOS Stream 和 RHEL 8+。文件会话通过 SSH 命令通道调用 Bash、GNU coreutils、GNU findutils、grep、tar、sha256sum、dd、tail、stat 和 mktemp；不会安装常驻辅助程序。解压不同归档格式需要服务器预先安装对应工具，例如 unzip、gzip、bzip2、xz 或 zstd。

首次连接会显示 SSH 主机指纹供核对。SSH 密码由 Windows 凭据能力加密保存。文件会话启动后会检查服务器系统和基础命令能力。

## 操作规则

远端操作由图形界面收集来源、目标和处理策略，不另行预检。复制、剪切粘贴、拖放移动和解压在参数齐全后直接执行，不显示执行确认或命令预览弹窗。`Ctrl+V` 和拖放移动默认强制覆盖；右键粘贴可选覆盖或跳过，解压另支持仅较新来源处理。选择解压目录时，点击“解压到此目录”即执行。

复制、移动和解压使用服务器原生命令；文件夹复制递归并保留权限与修改时间，不伪造所有者。上传和下载通过 SSH 传输所需字节流。文本保存经确认后写入服务器同目录临时文件并原子替换。

归档由服务器已有的 Linux 解压工具直接展开到所选目标目录。归档安全边界遵循服务器原生命令，不做预先展开扫描，也不提供自定义归档解析器。

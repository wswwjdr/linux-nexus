# 文件浏览与操作

文件管理器通过 SSH 命令通道在服务器上读取目录和属性。会话启动时会检查服务器发行版及基础命令；正式支持 Ubuntu、Debian、CentOS Stream 和 RHEL 8+，且不会在服务器安装常驻程序。

## 浏览与选择

文件列表支持图标视图、详细信息视图、排序、路径导航、框选和多选。目录、普通文件、符号链接及其他文件类型都可以浏览；符号链接和设备等特殊项目不参与文件操作。

在图标或详细信息视图中，可将选中的远端项目拖到另一文件夹以移动。文件夹不能移动到自身或子目录。文件夹内部项目的处理遵循服务器原生命令语义，应用不预先扫描目录树。

## 复制与移动

右键“复制／剪切”或按 `Ctrl+C` / `Ctrl+X` 时，应用仅记录源路径、复制或剪切模式及所属服务器，不执行远端命令。粘贴时取得目标目录和处理策略，再结合已记录的来源组装完整的 `cp` / `mv` 命令；参数齐全后直接通过 SSH 发送到服务器执行，不显示执行确认或命令预览弹窗。剪切在粘贴时对应服务器上的移动操作。

选中项目后按 `Ctrl+C` 复制，按 `Ctrl+X` 剪切，切换到目标目录后按 `Ctrl+V` 直接按强制覆盖策略粘贴。右键空白处或目标文件夹中的“粘贴”可选择处理策略：

- 强制覆盖 `-f`：使用服务器命令的强制覆盖选项；权限和目录结构限制仍然生效。
- 跳过已有目标 `-n`：移动时跳过已有同名目标；复制目录时仍递归处理内容，按 `cp -n` 语义保留已有文件并复制缺少的项目。

右键选择粘贴策略后即通过 SSH 命令通道执行服务器命令。应用不先检查来源、目标或冲突，路径无效、权限不足和冲突错误由服务器命令返回。复制文件夹使用递归复制，并保留权限和修改时间，不保留所有者或用户组。移动使用服务器 `mv` 原生语义；跨文件系统时由 `mv` 执行复制后删除。强制覆盖移动成功后会清除匹配的剪切记录；跳过策略、失败或取消时保留剪切记录，因为命令结束不代表所有来源都已移走。复制记录保留，可继续粘贴。

拖动时只记录来源，放到目标文件夹后直接执行 `mv -f`，不弹确认框。`mv -f` 不合并同名非空文件夹，遇到这类目标时服务器会报错。远端文件内容不经 Windows 中转；执行状态显示在文件列表中，可取消操作。成功、失败或取消后刷新相关目录，失败时显示服务器 stderr；部分成功不会回滚。

## 新建与删除

新建文件夹输入名称后执行一次服务器 `mkdir` 命令，不覆盖同名项目。按 `Delete` 或从右键菜单选择删除后，会先确认，再由服务器以一次 `rm -r` 命令处理所选普通文件和文件夹。删除不可撤销，不能删除服务器根目录。

## 解压

支持 `.zip`、`.tar`、`.tar.gz`、`.tgz`、`.tar.bz2`、`.tbz2`、`.tar.xz`、`.txz`、`.tar.zst` 和 `.tzst`。右键“解压”菜单按目标位置列出强制覆盖 `-f`、跳过已有目标 `-n`、仅较新来源处理 `-u`；目标可选当前目录、压缩包同名目录或远端目录选择器。

解压到当前目录或压缩包同名目录时，点击目标和策略对应的菜单项即执行。选择其他目录时，先记录压缩包和策略，目录选择器中的浏览不会触发解压；点击“解压到此目录”后直接执行，取消选择则不解压。目录选择器支持新建目录，新建目录是独立操作。解压不显示执行确认或命令预览弹窗。服务器使用 `tar`、`unzip` 和对应压缩工具直接展开到目标目录，不先扫描归档内容。tar 不恢复归档中的所有者和权限。缺少所需工具时，服务器命令失败并显示原始错误；应用不会自动检测或安装依赖。

解压能力和安全边界以服务器原生命令为准，不使用 Python，也不承诺自定义归档解析器级别的防护。解压中断或失败时，服务器工具可能已经写入部分目标文件；这些文件不会自动回滚。执行期间可取消，结束后刷新相关目录。

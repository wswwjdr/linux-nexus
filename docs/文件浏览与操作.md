# 文件浏览与操作

连接服务器后，应用从根目录 `/` 显示远端文件和文件夹。目录中的隐藏项也会显示；`.` 和 `..` 不作为列表条目显示。

## 浏览目录

点击文件夹名称进入该目录。路径栏提供返回根目录、返回上级目录和面包屑导航，点击路径中的任一级即可返回该位置。点击顶部刷新按钮重新读取当前目录。

文件列表可切换为图标视图或详细信息视图。详细信息视图显示名称、大小、修改时间和权限；悬停名称可查看完整名称。点击列标题可按名称、大小、修改时间或权限排序，再次点击可切换升序和降序。目录始终排在文件前面。

在列表空白处按住鼠标左键并拖动可框选多个文件或文件夹。按住 `Ctrl`（macOS 上为 `Command`）拖动可将框选结果加入现有选择；按住该键单击条目可切换它的选择状态。单击一个条目后，按住 `Shift` 单击另一个条目可连续选中两者之间的所有条目；按住 `Ctrl+Shift`（macOS 上为 `Command+Shift`）可将该范围加入现有选择。

在图标视图或详细信息视图中，可将单个文件或文件夹拖到当前列表中的另一个文件夹以移动；拖动已选条目时会移动全部已选项目。目标文件夹会高亮，移动期间不能开始另一项拖放移动。此操作仅适用于同一 SFTP 会话和当前目录中的条目；不能移动服务器根目录、符号链接或其他非普通文件/文件夹，也不能将文件夹移入自身或其子目录。

默认视图可在应用设置中选择。浏览时也可临时切换视图；设置入口和保存方式见[应用设置](应用设置.md)。

## 文件和文件夹操作

右键菜单分为三类：右键单个文件或文件夹时打开单项菜单；右键多个已选项目中的任一项时保留选择并打开批量菜单；右键未选项目时会先只选中该项目，再打开单项菜单。单项文件菜单可预览、倒序预览（支持时）、下载、复制、剪切、复制路径或删除；单项文件夹菜单可下载、复制、剪切、粘贴到该文件夹、复制路径或删除。批量菜单可下载、复制、剪切或删除所有已选项目。文件列表空白处的右键菜单独立于条目选择，会清空选择，并提供排序、复制当前目录路径、粘贴到当前目录、新建文件夹和上传文件。

聚焦浏览区域后按 `Ctrl+C` 可复制已选中的文件或文件夹，按 `Ctrl+X` 可剪切，按 `Ctrl+V` 可粘贴到当前目录。剪切后粘贴会移动项目；复制或剪切的项目都可在同一服务器配置的其他 SFTP 会话中粘贴。按 `Delete` 可打开删除确认；有多个条目被选中时会一次确认并删除所选条目。也可聚焦条目后按键盘菜单键或 `Shift+F10` 打开相应的单项或批量菜单。

“复制路径”会复制以 `/` 开头的远端绝对路径。“复制”和“剪切”会将选中的远端文件或文件夹放入应用内剪贴板，可在同一服务器配置的其他 SFTP 会话中使用。空白处的“粘贴”或 `Ctrl+V` 会将项目复制或移动到当前目录；文件夹菜单中的“粘贴到文件夹”会将项目复制或移动到该文件夹。同目录复制会自动命名为“副本”；同目录剪切不会移动项目。其他目录中遇到同名项目时可选择覆盖或跳过，同名文件夹会递归合并。成功剪切的项目会从剪贴板移除；失败、跳过或部分合并的项目仍保留在剪贴板中。新建文件夹不会覆盖已有同名项。删除文件前会确认；删除文件夹时会递归删除其中所有内容。删除无法撤销，服务器根目录不能删除。符号链接等非普通文件或文件夹不支持这些操作。

远端移动在目标不存在时使用 SFTP 重命名。拖放移动仅支持当前列表中的项目；剪切粘贴可将项目移动到其他目录。同名文件夹会递归合并，保留目标目录中来源没有的内容；合并过程中遇到同名文件时，可选择覆盖或跳过该文件，也可选择后续文件均覆盖或均跳过。文件与文件夹同名属于类型冲突，需单独选择替换或跳过；替换会先删除整个目标项及其内容，无法撤销。取消移动只停止尚未处理的内容，已完成的移动不会回滚；单项失败会显示在结果汇总中。若服务器因跨远端文件系统而拒绝 SFTP 重命名，移动会失败，不会改用复制后删除。

文件类型分类、预览大小限制和播放操作见[文件预览](文件预览.md)；下载和上传的行为见[文件传输](文件传输.md)。

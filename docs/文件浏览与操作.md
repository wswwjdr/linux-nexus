# 文件浏览与操作

文件管理器通过 SSH 命令通道在服务器上读取目录和属性。会话启动时会检查服务器发行版及基础命令；正式支持 Ubuntu、Debian、CentOS Stream 和 RHEL 8+，且不会在服务器安装常驻程序。

## 浏览与选择

文件列表支持图标视图、详细信息视图、排序、路径导航、框选和多选。目录、普通文件、符号链接及其他文件类型都可以浏览；符号链接和设备等特殊项目不参与文件操作。

在图标或详细信息视图中，可将选中的远端项目拖到另一文件夹以移动。文件夹不能移动到自身或子目录。文件夹树中包含符号链接或特殊文件时，操作会被拒绝。

## 复制与移动

选中项目后按 `Ctrl+C` 复制，按 `Ctrl+X` 剪切，切换到目标目录后按 `Ctrl+V` 直接按强制覆盖策略粘贴。命令发送前会显示操作确认弹窗。右键空白处或目标文件夹中的“粘贴”可选择处理策略：

- 强制覆盖 `-f`：使用服务器命令的强制覆盖选项；权限和目录结构限制仍然生效。
- 跳过已有目标 `-n`：目标已存在时跳过。
- 确认后处理：在确认弹窗选择遇到同名项目时全部覆盖或全部跳过；应用不先扫描服务器目标。

需要选择处理策略的操作由图形界面提供选项；确认后应用直接通过 SSH 命令通道执行服务器命令。应用不先检查来源、目标或冲突，路径无效、权限不足和冲突错误由服务器命令返回。复制文件夹使用递归复制，并保留权限和修改时间，不保留所有者或用户组。移动使用服务器 `mv` 原生语义；跨文件系统时由 `mv` 执行复制后删除。成功移动后会清除剪贴板中的剪切项目；失败时剪贴板保留。

拖放移动会显示命令确认，远端文件内容不经 Windows 中转。命令失败时显示服务器 stderr；多项命令产生的部分成功不会回滚。

## 新建与删除

新建文件夹输入名称后执行一次服务器 `mkdir` 命令，不覆盖同名项目。按 `Delete` 或从右键菜单选择删除后，会先确认，再由服务器以一次 `rm -r` 命令处理所选普通文件和文件夹。删除不可撤销，不能删除服务器根目录。

## 解压

支持 `.zip`、`.tar`、`.tar.gz`、`.tgz`、`.tar.bz2`、`.tbz2`、`.tar.xz`、`.txz`、`.tar.zst` 和 `.tzst`。右键“解压”菜单按目标位置列出强制覆盖 `-f`、跳过已有目标 `-n`、仅较新来源处理 `-u` 和确认后处理；目标可选当前目录、压缩包同名目录或远端目录选择器。

确认弹窗显示归档、目标和将发送的命令；选择“确认后处理”时，也可在弹窗选择遇到同名项目时全部覆盖或全部跳过。确认后服务器使用 `tar`、`unzip` 和对应压缩工具直接展开到目标目录，不先扫描归档内容。tar 不恢复归档中的所有者和权限。缺少所需工具时，服务器命令失败并显示原始错误；应用不会自动检测或安装依赖。

解压能力和安全边界以服务器原生命令为准，不使用 Python，也不承诺自定义归档解析器级别的防护。解压中断或失败时，服务器工具可能已经写入部分目标文件；这些文件不会自动回滚。

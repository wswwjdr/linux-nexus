# 文件浏览与操作

连接服务器后，应用从根目录 `/` 显示远端文件和文件夹。目录中的隐藏项也会显示；`.` 和 `..` 不作为列表条目显示。

## 浏览目录

点击文件夹名称进入该目录。路径栏提供返回根目录、返回上级目录和面包屑导航，点击路径中的任一级即可返回该位置。点击顶部刷新按钮重新读取当前目录。

文件列表可切换为图标视图或详细信息视图。详细信息视图显示名称、大小、修改时间和权限；悬停名称可查看完整名称。点击列标题可按名称、大小、修改时间或权限排序，再次点击可切换升序和降序。目录始终排在文件前面。

默认视图可在应用设置中选择。浏览时也可临时切换视图；设置入口和保存方式见[应用设置](应用设置.md)。

## 文件和文件夹操作

在文件或文件夹上单击右键打开操作菜单，也可聚焦条目后按键盘菜单键或 `Shift+F10`。文件可预览、下载、复制路径或删除；`.txt`、`.sh` 和 `.log` 文件还可打开倒序预览。文件夹可下载、复制路径或删除。在文件列表空白处单击右键，可复制当前目录路径、新建文件夹或上传文件。

“复制路径”会复制以 `/` 开头的远端绝对路径。新建文件夹不会覆盖已有同名项。删除文件前会确认；删除文件夹时会递归删除其中所有内容。删除无法撤销，服务器根目录不能删除。符号链接等非普通文件或文件夹不支持这些操作。

文件预览格式、大小限制和播放操作见[文件预览](文件预览.md)；下载和上传的行为见[文件传输](文件传输.md)。

# 多会话与 SSH 终端

顶部标签栏可同时打开多个 SSH 文件会话和终端会话。每个标签独立连接服务器；文件会话保留当前目录、视图和排序，终端会话保留终端内容。

## 新建与切换

点击标签栏右侧“新建会话”，选择服务器和连接类型。服务器列表中单击服务器会打开文件管理；右键服务器可选择文件管理或 SSH 终端。

文件管理会话顶部的终端按钮会从当前远端目录打开 SSH 终端。终端中的“文件管理”按钮会切换到该服务器已有的文件会话，或新建文件会话。

文件工具栏的“进入 root 模式”只提升当前文件标签。服务器要求认证时，输入 sudo 密码。进入后，浏览、传输、解压和运行脚本等文件操作都以 root 执行，沿用原有操作流程。点击“退出 root 模式”会取消该标签的文件任务、关闭预览并刷新目录。重连和复制标签时使用 SSH 登录身份，直接以 root 登录时显示“root 登录”。

在 SSH 终端中，服务器允许时可用 `sudo -i` 进入 root Shell，再用 `exit` 返回登录账号。终端和文件标签的身份各自独立。

点击标签切换会话。右键标签并选择“复制会话”会使用相同服务器和连接类型新建会话；文件会话会保留当前目录、视图和排序，终端沿用起始目录。

拖动会话标签可调整顺序，蓝色竖线标示放置位置；拖到标签栏边缘可滚动查看其他标签。标签获得焦点时，也可用 `Ctrl+Shift+←` / `Ctrl+Shift+→` 左右移动。排序不会切换当前会话或重新连接，顺序在本次应用运行期间保留。

## 性能监控

在已连接的文件管理或 SSH 终端标签页，点击工具栏中的 CPU、内存和磁盘摘要，然后开启“实时监控”。同一条服务器配置下的所有标签页共享开关和最新读数，同一配置只运行一组采样任务。分别保存的服务器配置独立监控，即使主机地址和端口相同。

监控开启且服务器至少有一个会话保持连接时，关闭面板或切换到其他服务器后，采样会在后台继续。采样使用的连接断开后，同一配置下仍在线的连接会自动接替，界面保留最近读数。关闭监控开关或断开最后一个会话时，采样停止并清空读数。本次应用运行期间重新连接时会恢复原开关，重启应用后默认关闭。删除配置或修改主机、端口、用户名也会清除该配置的监控开关。

面板显示整机和逐逻辑 CPU 使用率、1/5/15 分钟系统负载、运行时间、内存、Swap、本地挂载点容量、逐块设备读写速率与 IOPS，以及逐网卡收发速率。开始采样或更换采样连接后，CPU 使用率及磁盘和网络速率需要两次有效采样才能计算。手动刷新会同时请求内核指标和挂载点容量。面板保留各指标的最新读数，采样失败时显示标有时间的上次成功读数。

采样通过现有 SSH 连接以登录身份读取 Linux 的 `/proc`，挂载点容量单独使用 GNU `df` 探测本地文件系统。无需安装代理或提升权限。若某项无法读取，其余指标仍会更新。查看具体进程时，可在 SSH 终端中运行服务器上已安装的 `htop`。

关闭标签会断开该标签的 SSH 连接并取消该会话中的活动操作。连接意外中断时，可在标签内重连。应用退出后不会恢复原会话；可在[应用设置](应用设置.md)中设置启动连接。

## 快捷键

窗口左上角的键盘按钮列出文件管理、SSH 终端和通用快捷键。终端中 `Ctrl+C` 会发送给远端 Shell；`Ctrl+Shift+C` 和 `Ctrl+Shift+V` 用于复制和粘贴终端文本。

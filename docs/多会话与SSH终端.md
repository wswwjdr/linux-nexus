# 多会话与 SSH 终端

顶部标签栏可同时打开多个 SSH 文件会话和终端会话。每个标签独立连接服务器；文件会话保留当前目录、视图和排序，终端会话保留终端内容。

## 新建与切换

点击标签栏右侧“新建会话”，选择服务器和连接类型。服务器列表中单击服务器会打开文件管理；右键服务器可选择文件管理或 SSH 终端。

文件管理会话顶部的终端按钮会从当前远端目录打开 SSH 终端。终端中的“文件管理”按钮会切换到该服务器已有的文件会话，或新建文件会话。

点击标签切换会话。右键标签并选择“复制会话”会使用相同服务器和连接类型新建会话；文件会话会保留当前目录、视图和排序，终端沿用起始目录。

## 性能监控

已连接的文件会话和终端会话可查看服务器 CPU、内存、根分区、负载和运行时间。采样通过 SSH 命令读取 `/proc` 和根分区状态，不安装远端代理、不需要管理员权限。趋势保存在内存中，最多保留 15 分钟。

关闭标签会断开该标签的 SSH 连接并取消该会话中的活动操作。连接意外中断时，可在标签内重连。应用退出后不会恢复原会话；可在[应用设置](应用设置.md)中设置启动连接。

## 快捷键

窗口左上角的键盘按钮列出文件管理、SSH 终端和通用快捷键。终端中 `Ctrl+C` 会发送给远端 Shell；`Ctrl+Shift+C` 和 `Ctrl+Shift+V` 用于复制和粘贴终端文本。

# 多会话与 SSH 终端

应用顶部的会话标签栏可同时打开多个 SFTP 文件管理器和 SSH 终端。每个标签独立连接服务器；切换标签时，各 SFTP 会话保留自己的目录和浏览状态，终端会话保留自己的终端内容。

## 新建会话

点击标签栏右侧的“新建会话”按钮，选择已保存的服务器和连接方式，然后点击“连接”。在服务器列表中左键单击服务器会直接打开 SFTP 文件管理器；右键单击服务器可选择 SFTP 文件管理或 SSH 终端。

在 SFTP 文件管理器中，点击顶部的终端按钮可为当前服务器新建 SSH 终端。新终端会从当前远端目录开始；通过“新建会话”选择 SSH 终端时，则从服务器默认目录开始。

终端中的“文件管理”按钮会切换到该服务器已有的 SFTP 会话；如果尚未打开 SFTP 会话，则新建一个。

## 切换与管理

点击标签可在会话之间切换。标签会显示服务器、会话类型和连接状态。同一服务器可同时打开多个 SFTP 或 SSH 标签，也可连接不同服务器。

在会话标签上右键单击并选择“复制会话”，会使用相同服务器和连接方式新建会话。SFTP 会话会保留当前目录、视图和排序方式；SSH 终端会沿用原会话的起始目录。

点击左上角的“首页”按钮可返回服务器列表。已有会话不会关闭，连接和各自状态都会保留；点击会话标签即可恢复该会话。

关闭标签会断开该标签对应的 SSH 连接，并取消该会话正在进行的操作；其他标签的连接和任务继续运行。会话只在应用运行期间保留，退出并重新启动应用后不会恢复；如需在启动时重新连接，可在[应用设置](应用设置.md)中指定服务器和会话类型。

连接意外中断时，标签和本地会话状态会保留。切换到该标签后，可点击“重连”重新连接。编辑服务器配置会断开该服务器的现有会话；删除服务器配置会关闭其相关标签。

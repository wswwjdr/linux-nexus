# 智能体助手

简体中文 | [English](assistant.md)

智能体助手位于 Linux Nexus 的文件管理界面，通过当前 SSH 文件会话执行模型根据任务生成的 Shell 命令，适用于诊断、文件操作、安装、构建部署和服务管理。

## 配置模型

1. 打开「设置 → 助手」，选择「添加服务商」。
2. 填写名称、服务商提供的 API Key，以及兼容 OpenAI Chat Completions 的 API 根地址，例如 `https://provider.example/v1`。地址填写到 API 根路径，省略 `/chat/completions`。远程地址必须使用 HTTPS，本机回环地址可以使用 HTTP。
3. 点击「获取模型」或手动填写模型 ID，每行一个，再选定默认模型。获取失败时仍可手动填写。可以保存多个服务商。
4. 点击「测试连接」，检查鉴权、普通对话、流式响应和工具调用，再点击「保存」。普通对话成功但工具调用失败时，换用支持工具调用的模型。

执行限制默认每次请求最多 100 个模型步骤，单次模型请求超时 120 秒。可在同一设置页调整，分别支持 1–1000 步和 5–300 秒。

## 执行任务

在文件管理顶部打开助手。发送任务时，助手会在提示词末尾附上当前远端目录。可在项目目录询问后台服务端口，也可直接说明日志分析、构建或部署任务。下一条命令由模型根据目标和已取得的结果决定。

默认使用手动模式。应用会展示命令、工作目录，并在执行命令或向进程发送普通输入前等待批准。自动模式会直接执行任务授权范围内的操作。模式按服务器和执行身份记忆，每轮开始时读取一次。

命令卡片显示实际脚本、实时输出、分页日志、退出码和耗时。每条命令有独立的工作目录和 Shell。长任务可以持续运行，也可以使用「停止」取消。需要密码时，使用命令卡片中的密码框。

收起助手或切换标签后任务继续。同一会话每次运行一轮，不同会话和文件管理操作可以并行。退出时应用尝试停止受管理的进程。断线或无法确认终止时，重试前先核实服务器状态。

## 提示词与数据

在「设置 → 助手」编辑全局提示词或恢复默认。内置默认提示词跟随应用语言，自定义内容原样使用。在「服务器提示词」中选择任意已保存的连接，为其编辑完整覆盖或切回全局提示词。服务器未连接也可以编辑。修改从下一轮生效。

打开「会话历史」可搜索会话并查看最近活动和状态。使用每行的更多操作重命名或删除会话。删除活动会话前，需先停止任务。旧历史文件保留在原处，新历史从空列表开始。

所选模型服务商会接收命令及其原始文本输出、请求和相关上下文。专用密码框将输入直接送入对应进程，并遮蔽输出中匹配的原值。API Key、会话内容和日志使用系统加密存储。中断的命令在应用重启后需要重新核实。

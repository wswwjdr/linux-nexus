# 文件预览

文件列表中的文件可通过右键菜单打开预览；在文件搜索中，点击文件结果并选择“预览”也可打开预览。应用按文件扩展名识别格式，扩展名不区分大小写；只支持普通文件。

| 类型 | 支持格式 | 显示方式 |
| --- | --- | --- |
| 图片 | `.jpg`、`.jpeg`、`.png`、`.gif` | 在弹窗中显示图片 |
| 文本 | `.txt`、`.sh`、`.log` | 在弹窗中编辑并保存到服务器 |
| 音频 | `.mp3` | 使用播放器播放 |
| 视频 | `.mp4` | 使用播放器播放 |

其他文件格式点击预览时会提示“暂不支持的文件类型”。

## 预览大小上限

每种文件类型的预览上限独立设置，默认值如下：

| 类型 | 默认上限 |
| --- | ---: |
| 文本 | 5 MiB |
| 图片 | 100 MiB |
| 音频 | 100 MiB |
| 视频 | 100 MiB |

在窗口顶部的设置中可调整上限，每项必须是 `1` 至 `1024` MiB 之间的整数。应用会在读取前检查文件大小；文本和图片读取期间也会继续限制数据量。倒序预览从文件末尾分段读取，每页最多读取 256 KiB，已加载内容累计达到文本上限后停止；因此大于上限的日志仍可从末尾查看。音视频上限按远端文件总大小判断，但不会预先读取完整文件；例如预览 1 GiB 视频，需将视频上限设为 1024 MiB。超过上限的文件无法预览，请下载后查看。设置保存方式见[应用设置](应用设置.md)。

## 预览操作

- 文本以 UTF-8 编码显示，可直接编辑。内容发生修改后，点击“保存”并确认即可覆盖服务器上的同一路径文件。保存前会校验预览后的远程内容是否发生变化；若已变化，应用会拒绝覆盖，需重新打开预览后再保存。写入会先在同一目录创建临时文件，完成后替换原文件，并保留原文件权限和统一的原有换行格式。
- `.txt`、`.sh` 和 `.log` 文件可在右键菜单中选择“倒序预览”。倒序预览只加载文件的一部分，保持只读；预览从文件末尾开始，按原有顺序显示，滚动到内容顶部会读取更早部分，直到文件开头或达到文本预览上限。打开时读取当前文件内容，不会自动跟随新增日志。
- 图片打开时会适配预览区域。滚动鼠标滚轮可缩放，范围为 `25%` 至 `400%`；缩放以鼠标指针位置为锚点。
- 音频和视频使用播放器控件播放。视频可通过进度条跳转；聚焦视频播放器后，按左或右方向键可后退或前进 5 秒。

文本内容在内存中读取。图片会暂存在本机临时目录；音频和视频根据播放器请求的字节范围从服务器读取，不会预先完整复制到本机。关闭预览或退出应用时会停止媒体读取并清理预览资源。

# 文件预览

文件列表和搜索结果的右键菜单按文件类型显示可用操作。预览位于所属会话的工作区内，顶部会话标签仍可切换。服务器文件通过 SSH 读取；独立图片预览使用本机临时文件，PDF、音频和视频按查看器或播放器请求的字节范围读取。Markdown 正文中的服务器图片按需流式读取，HTTP/HTTPS 图片由渲染进程访问网络地址。

| 类型 | 默认后缀示例 | 显示方式 |
| --- | --- | --- |
| 文本 | `.txt`、`.sh`、`.log`、`.json`、源码 | 在线编辑并保存到服务器 |
| Markdown | `.md`、`.markdown` | 只读渲染、目录、代码高亮与复制、正文图片 |
| PDF | `.pdf` | Chromium 内置 PDF 查看器 |
| 图片 | `.jpg`、`.png`、`.gif`、`.webp`、`.svg` | 缩放、拖拽、旋转、翻转和适应窗口 |
| 音频 | `.mp3`、`.wav`、`.ogg`、`.m4a`、`.flac` | 原生音频控件、快捷键与装饰动画 |
| 视频 | `.mp4`、`.m4v`、`.webm`、`.mov` | Video.js 中文控件、快捷键、倍速和全屏 |
| 脚本 | `.sh`、`.bash`、`.zsh`、`.py` | 右键菜单在服务器执行 |

后缀匹配不区分大小写，并使用第一个点之后的完整文件名部分；例如 `app.min.js` 匹配 `.min.js`。应用设置可增删每类后缀。仅普通文件提供文件类型操作。

## 读取范围

文本和 Markdown 通过 SSH stdout 读取内容，默认上限为 5 MiB。图片会流到本机临时目录，默认上限 100 MiB。PDF 和音视频根据文件大小检查预览上限，并由 Chromium 或播放器按 Range 请求读取对应字节，不会预先完整下载。各类型上限可在设置中填写正整数 MiB，不设最大值。

倒序日志预览使用服务器 `stat` 和范围读取命令，从文件末尾分页读取，默认与文本使用相同上限。打开后不会跟随新增内容。

倒序预览同样支持搜索按钮和 `Ctrl+F`，匹配计数、高亮、区分大小写和跳转快捷键与文本预览一致。搜索范围为当前已加载的内容，默认定位靠近文件末尾的匹配；向上滚动加载更早日志后会更新匹配计数，保留当前匹配和阅读位置。未加载的内容不参与搜索，达到预览上限后也不会继续读取。

## 在线编辑

文本预览底部的搜索按钮或 `Ctrl+F`（macOS 为 `Cmd+F`）打开内容搜索，默认不区分大小写，按字面文本匹配。搜索栏显示当前匹配序号与总数，并高亮、滚动定位当前匹配；可切换区分大小写。`Enter` / `Shift+Enter` 在搜索框内切换下一处 / 上一处，`F3` / `Shift+F3` 在预览内执行同样操作，首尾循环。选中文本后打开搜索会自动填入选中内容。`Esc` 先收起搜索栏并回到编辑区，再次按下关闭预览。搜索包含尚未保存的编辑内容，不修改文件。

文本支持 UTF-8 和 GBK，界面显示保存编码。优先识别 UTF-8（含 BOM），无法按 UTF-8 读取时尝试 GBK；自动选择仅是候选，不能证明文件的真实编码。可明确选择按 UTF-8／GBK 重新加载；有草稿时会先确认是否放弃。默认保留原编码和 UTF-8 BOM，转换为 UTF-8 必须点击对应按钮。无法无损解码，或新增字符不能用保存编码表示时拒绝保存，不用替换字符代替原文。统一换行沿用原格式；原文件换行混合时，保存规范为 LF。

保存前由图形界面确认。预览记录原始字节 SHA-256 和文件身份，保存会在提交前重新比较；发现外部修改时保留草稿，用户可取消后重新加载，或再次明确选择“强制覆盖服务器文件”。成功后更新版本。这个检查不能消除检查与改名之间其他程序写入的竞态窗口，不提供跨程序的严格原子比较替换。

保存会检查远程 SSH 会话是否提供 `getfacl` 和 `getfattr`。缺少工具时，弹窗列出对应的 `acl`、`attr` 软件包。确认后，应用通过服务器的包管理器安装缺少的包，必要时请求远程 sudo 密码。安装成功后继续保存当前草稿。取消或安装失败时保留草稿。

内容写入同目录临时文件，完整字节和生产者提交记录通过 SHA-256 验证后才允许替换。保存会检查所有者、用户组、权限、ACL 和扩展属性是否完整保留。权限不足或校验失败时保留原文件。多硬链接文件和符号链接拒绝原子替换。保存不承诺磁盘故障或掉电后的持久性；若提交后连接中断，结果可能未知，需要重新加载确认。

## Markdown 只读预览

正文居中展示，最大阅读宽度为 960px，随应用切换深浅主题。支持标准 Markdown 和 GFM（GitHub Flavored Markdown）扩展，包括表格、任务列表和删除线。代码块提供离线语法高亮与复制，宽代码块和表格可独立横向滚动。预览不提供编辑、保存或导出；Mermaid 图表显示为代码，数学公式保留源码，原始 HTML 不执行也不渲染。

标题栏的目录按钮展开或收起章节目录，点击章节或正文标题锚点可跳转，目录标记当前章节。重复标题生成独立锚点。HTTP/HTTPS 链接在系统默认浏览器中打开，指向其他服务器文件的链接显示为不可跳转文本。

正文图片支持相对 Markdown 所在目录的路径、当前服务器绝对路径，以及 HTTP/HTTPS 地址。服务器图片按当前会话的读取权限、图片类型设置和单张图片预览大小上限校验，按需加载；关闭或替换文档、断开连接时撤销访问并终止进行中的读取。网络图片不发送页面来源信息，需要网络可达。图片加载失败只显示局部占位，不影响其他正文；点击图片不打开额外查看器。

## 图片预览

图片查看器铺满当前工作区，顶部显示文件名及原始像素尺寸，底部工具栏提供缩小、放大、适应窗口、左右旋转 90°、水平翻转和垂直翻转。滚轮以鼠标位置为缩放锚点，工具栏按钮以视口中心缩放；按住鼠标左键拖动可平移。加载失败时可点击重试。

缩放百分比相对于适应窗口的基准：初始适配显示 100%，不一定等于原始像素大小；小图初始不会放大。范围为 10%–1000%，每步调整 15 个百分点。“适应窗口”重置缩放和平移，保留旋转和翻转，并按旋转后的边界适配。工作区尺寸变化会更新适配基准，保留相对缩放和变换状态。

点击图片区域之外的空白处、关闭按钮或按 Esc 退出；拖拽结束不触发误关闭。预览工具栏不提供下载，下载原文件仍从文件管理器执行。

## 音视频预览

音频使用原生控件，配有黑胶唱片和音柱装饰动画；动画表示播放状态，不是真实频谱。视频使用 Video.js 8.23.7 的中文控件，提供播放进度、音量、倍速和全屏。标题栏的快捷键按钮可展开或收起帮助面板。

打开时从头尝试有声播放；自动播放被阻止时保持暂停并提示手动播放，不会自动静音。加载或解码失败会显示错误，格式支持取决于 Electron 的媒体解码能力，不提供转码。

| 快捷键 | 音频和视频 |
| --- | --- |
| Space / K | 播放／暂停；按钮上的 Space 保留按钮操作 |
| ← / → | 后退／前进 5 秒；视频的 → 短按在松开时跳转 |
| J / L | 后退／前进 10 秒 |
| ↑ / ↓ | 音量增加／减少 10 个百分点 |
| M | 静音／取消静音 |
| Home / End | 跳至开头／结尾 |
| < / > | 减速／加速 0.25 倍，范围 0.25–4 倍 |
| Esc | 关闭预览；视频全屏时先退出全屏，再按 Esc 关闭 |

视频额外支持 F 切换全屏；长按 → 达到 500ms 后临时使用 2 倍速，松开恢复原速且不额外跳转。窗口失焦或切换会话会取消长按状态。输入框、菜单和组合快捷键不触发这些媒体快捷键。

## 会话与资源生命周期

切换会话保留所属预览：图片保留变换，Markdown 保留阅读位置；音视频立即暂停并保留当前进度，返回后手动继续。隐藏会话不响应播放器快捷键。

关闭后重新打开会重置阅读、图片变换和播放器状态；音视频不保存历史进度、音量、倍速或帮助面板展开状态。断开连接会关闭所属预览；关闭、替换预览或退出应用时释放对应临时资源和进行中的读取。

# 文件预览

文件列表和文件搜索结果的右键菜单会按文件类型显示可用操作。应用内置文本、Markdown、PDF、图片、音频、视频和脚本类型，用户可调整各类型的后缀。匹配不区分大小写，并将文件名第一个点之后的完整部分作为后缀：`app.min.js` 只匹配 `.min.js`，`.profile` 匹配 `.profile`。同一个后缀可加入多个类型，例如 `.md` 默认同时提供文本、Markdown 和倒序预览能力；`.sh` 同时提供文本预览、倒序预览和脚本操作。只对普通文件提供文件类型操作。

| 类型 | 默认后缀示例 | 显示方式 |
| --- | --- | --- |
| 文本 | `.txt`、`.sh`、`.log`、`.json`、`.yaml`、常见源码 | 在弹窗中编辑并保存到服务器 |
| Markdown | `.md`、`.markdown` | 只读渲染 Markdown 和 GFM |
| PDF | `.pdf` | 使用 Chromium 内置 PDF 查看器 |
| 图片 | `.jpg`、`.jpeg`、`.png`、`.gif`、`.webp`、`.svg` | 在弹窗中查看图片 |
| 音频 | `.mp3`、`.wav`、`.ogg`、`.m4a`、`.flac` | 使用播放器播放 |
| 视频 | `.mp4`、`.m4v`、`.webm`、`.mov` | 使用播放器播放 |
| 脚本 | `.sh`、`.bash`、`.zsh`、`.py` | 右键菜单可执行或调整命令后执行 |

完整默认后缀列表以及添加、移除方式见[应用设置](应用设置.md)。设置页会说明每类后缀启用的操作。多种预览方式匹配时，可在预览子菜单中选择组件；多种类型同时匹配时会组合显示其全部专属操作。

## 预览大小上限

每种文件类型的预览上限独立设置，默认值如下：

| 类型 | 默认上限 |
| --- | ---: |
| 文本 | 5 MiB |
| Markdown | 5 MiB（共用文本上限） |
| PDF | 100 MiB |
| 图片 | 100 MiB |
| 音频 | 100 MiB |
| 视频 | 100 MiB |

在窗口顶部的设置中可调整上限，每项必须是 `1` 至 `1024` MiB 之间的整数。应用会在读取前检查文件大小；文本和图片读取期间也会继续限制数据量。PDF 和音视频按远端文件总大小判断，但不会预先读取完整文件；例如预览 1 GiB 视频，需将视频上限设为 1024 MiB。超过上限的文件无法预览，请下载后查看。设置保存方式见[应用设置](应用设置.md)。

## 预览操作

- 文本以 UTF-8 编码显示，可直接编辑。内容发生修改后，点击“保存”并确认即可覆盖服务器上的同一路径文件。保存前会校验预览后的远程内容是否发生变化；若已变化，应用会拒绝覆盖，需重新打开预览后再保存。写入会先在同一目录创建临时文件，完成后替换原文件，并保留原文件权限和统一的原有换行格式。
- Markdown 预览支持 GFM 表格、任务列表和删除线；不解析原始 HTML，也不加载内嵌图片。点击 HTTP 或 HTTPS 链接会在系统默认浏览器中打开。
- 关联了文本预览的文件可在右键菜单中选择“倒序预览”。倒序预览只加载文件的一部分，保持只读；预览从文件末尾开始，按原有顺序显示，滚动到内容顶部会读取更早部分，直到文件开头或达到文本预览上限。打开时读取当前文件内容，不会自动跟随新增日志。
- 图片打开时会适配预览区域。滚动鼠标滚轮可缩放，范围为 `25%` 至 `400%`；缩放以鼠标指针位置为锚点。
- 音频和视频使用播放器控件播放。视频可通过进度条跳转；聚焦视频播放器后，按左或右方向键可后退或前进 5 秒。
- PDF 使用 Chromium 内置查看器。音视频格式能否播放取决于当前 Chromium 构建所支持的编解码器。

文本和 Markdown 内容在内存中读取。图片会暂存在本机临时目录；PDF、音频和视频根据查看器或播放器请求的字节范围从服务器读取，不会预先完整复制到本机。关闭预览或退出应用时会停止媒体读取并清理预览资源。

# 文件预览

文件列表和搜索结果的右键菜单按文件类型显示可用操作。预览数据由服务器命令通过 SSH 读取；图片内容会传到本机临时文件，PDF、音频和视频按播放器请求的字节范围分别执行远端读取命令。

| 类型 | 默认后缀示例 | 显示方式 |
| --- | --- | --- |
| 文本 | `.txt`、`.sh`、`.log`、`.json`、源码 | 在线编辑并保存到服务器 |
| Markdown | `.md`、`.markdown` | 只读渲染 Markdown 和 GFM |
| PDF | `.pdf` | Chromium 内置 PDF 查看器 |
| 图片 | `.jpg`、`.png`、`.gif`、`.webp`、`.svg` | 图片预览和缩放 |
| 音频 | `.mp3`、`.wav`、`.ogg`、`.m4a`、`.flac` | 音频播放器 |
| 视频 | `.mp4`、`.m4v`、`.webm`、`.mov` | 视频播放器 |
| 脚本 | `.sh`、`.bash`、`.zsh`、`.py` | 右键菜单在服务器执行 |

后缀匹配不区分大小写，并使用第一个点之后的完整文件名部分；例如 `app.min.js` 匹配 `.min.js`。应用设置可增删每类后缀。仅普通文件提供文件类型操作。

## 读取范围

文本和 Markdown 通过 SSH stdout 读取内容，默认上限为 5 MiB。图片会流到本机临时目录，默认上限 100 MiB。PDF 和音视频根据文件大小检查预览上限，并由 Chromium 或播放器按 Range 请求读取对应字节，不会预先完整下载。各类型上限可在设置中调整为 1 至 1024 MiB。

倒序日志预览使用服务器 `stat` 和范围读取命令，从文件末尾分页读取，默认与文本使用相同上限。打开后不会跟随新增内容。

## 在线编辑

文本保存前由图形界面确认。应用不检查文件自预览后是否被其他程序修改；保存会通过 SSH stdin 写入服务器同目录临时文件，保留原文件权限并原子改名。换行格式会沿用原文件统一使用的格式。

## 其他预览

Markdown 支持 GFM 表格、任务列表和删除线，不解析原始 HTML。HTTP/HTTPS 链接在系统默认浏览器中打开。图片可用滚轮缩放；音视频支持播放器控件和视频方向键跳转。预览关闭或应用退出时会释放临时资源及正在进行的媒体读取。

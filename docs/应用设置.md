# 应用设置

点击窗口顶部的设置按钮可打开应用设置。每项设置修改后立即应用并保存，在下次启动时继续使用。

## 外观主题

外观可选择“亮色”“暗色”或“跟随系统”，默认使用亮色。选择跟随系统后，应用会在 Windows 深浅色主题变化时自动切换；主题选择会保存在 `settings.json` 中。

## 默认文件视图

默认文件视图可选择“图标视图”或“详细信息”。首次使用时默认是详细信息视图。此项设置决定启动后浏览文件时采用的视图；浏览过程中也可在路径栏临时切换。此项与其他应用设置一同保存在 `settings.json` 中。

## 启动时连接

可选择一个已保存的服务器，并设置启动后打开 SFTP 文件管理或 SSH 终端。不选择服务器时，应用启动后进入首页且不连接服务器。启动连接会使用已保存的 SSH 密码，并遵循主机指纹确认流程。

## 命令别名

命令别名按服务器连接分别管理。选择服务器后可同步或重新同步该账号 Bash 交互环境中实际生效的 alias；同步状态和最近成功同步时间保存在本机的 `servers.json` 中。服务器地址、端口或用户名变更后，该连接的别名缓存会清除。

新增别名需要填写名称和实际命令。同名别名会要求确认覆盖。新增、覆盖和删除会修改服务器用户目录中的 `~/.bashrc`；删除和覆盖只在文件中存在唯一、整行完全匹配的单行定义时进行，否则应用会拒绝修改以避免误删或误改。若别名来自其他配置文件，应用会显示无法安全删除的原因。

别名功能首版仅支持 Bash。服务器操作使用已保存的连接凭据并遵循主机指纹确认流程。变更会在之后新开的 SSH 终端中生效，已打开终端不会自动重载配置。

## 预览格式和大小上限

设置中可维护文本、Markdown、PDF、图片、音频和视频六类预览后缀。同一后缀可加入多个类别；文件匹配到多个类别时，右键菜单会列出各预览方式。添加后缀时可输入带点或不带点的形式，应用会统一保存为小写点号格式；同一类别中的重复项会自动合并。恢复默认仅重置预览后缀，不影响其他设置。

各类别可分别调整预览上限，范围为 `1` 至 `1024` MiB。Markdown 使用文本上限。默认上限为文本和 Markdown `5` MiB，PDF、图片、音频和视频 `100` MiB。各类型的预览行为和限制见[文件预览说明](文件预览.md)。

数值输入需在对应范围内才会保存；每个有效值修改后立即生效，预览会按新的上限执行。

## 性能监控阈值

可分别设置 CPU、内存、根分区使用率和每核 1 分钟系统负载的“注意”与“严重”界限。每项注意值必须小于严重值，范围为 `0` 至 `100`；前三项单位为百分比，系统负载按逻辑 CPU 数归一。默认值为 CPU/内存 `75% / 90%`、根分区 `80% / 90%`、每核负载 `1 / 2`。达到界限时，右上角摘要和详情会改变状态颜色，不发送弹窗通知。

## 启动与本机偏好

应用同一时间只运行一个实例。如果再次启动，已有窗口会显示并获得焦点；窗口最小化时会先还原。

最近成功连接的时间保存在本机并用于服务器列表排序。正式安装时，应用设置、窗口存储、缓存、日志、崩溃转储和临时文件保存在 `%APPDATA%\linux-nexus\`，开发运行时保存在项目目录的 `data/` 下。主题、默认文件视图、预览设置、传输并发数、性能监控阈值和启动连接保存在其中的 `settings.json`；服务器配置、命令别名缓存和密码存储方式见[服务器连接与安全](服务器连接与安全.md)。搜索历史按服务器保存在本机，只包含搜索条件；详情见[文件搜索说明](文件搜索.md)。

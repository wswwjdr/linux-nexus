# 应用设置

点击窗口顶部的设置按钮可打开应用设置。有效设置修改后立即保存，并在下次启动时继续使用；具体生效时机见各项说明。数值不在有效范围内或性能阈值关系无效时不会保存，修正为有效值后才会应用。

## 外观主题

外观可选择“亮色”“暗色”或“跟随系统”，默认使用亮色。选择跟随系统后，应用会在 Windows 深浅色主题变化时自动切换；主题选择会保存在 `settings.json` 中。

## 默认文件视图

默认文件视图可选择“图标视图”或“详细信息”。首次使用时默认是详细信息视图。此项设置决定启动后浏览文件时采用的视图；浏览过程中也可在路径栏临时切换。此项与其他应用设置一同保存在 `settings.json` 中。

## 启动时连接

可选择一个已保存的服务器，并设置启动后打开 SSH 命令文件管理或 SSH 终端。不选择服务器时，应用启动后进入首页且不连接服务器。启动连接会使用已保存的 SSH 密码，并遵循主机指纹确认流程。

## 命令别名

命令别名按服务器连接分别管理。选择服务器后可同步或重新同步该账号 Bash 交互环境中实际生效的 alias；同步状态和最近成功同步时间保存在本机的 `servers.json` 中。服务器地址、端口或用户名变更后，该连接的别名缓存会清除。

新增别名需要填写名称和实际命令。同名别名会先读取服务器当前定义，再显示覆盖确认及将执行的命令。删除会先核对服务器状态，再显示确认。最终修改命令会重新校验预检时 `~/.bashrc` 的 SHA-256 与唯一、整行匹配的定义；文件发生变化时停止修改并要求重新预检。若别名来自其他配置文件，应用会显示无法安全删除的原因。

别名功能首版仅支持 Bash。服务器操作使用已保存的连接凭据并遵循主机指纹确认流程。变更会在之后新开的 SSH 终端中生效，已打开终端不会自动重载配置。

## 文件类型分类与预览大小上限

文件类型分类是应用级设置，供系统识别文件类型；它与预览大小上限分开管理。内置文本、Markdown、PDF、图片、音频、视频和脚本七类后缀，每类会说明它启用的操作；例如脚本类型提供执行和调整后执行。同一后缀可加入多个类别，匹配时会组合显示所有适用操作。后缀不区分大小写，并按文件名第一个点之后的完整部分精确匹配：`app.min.js` 只匹配 `.min.js`，隐藏文件 `.profile` 匹配 `.profile`。添加后缀时可输入带点或不带点的形式，应用会统一保存为小写点号格式；同一类别中的重复项会自动合并。设置页显示每类当前后缀，可添加、移除或恢复默认值。远端脚本的执行方式见[远端脚本执行](脚本执行.md)。

预览大小上限按文本、PDF、图片、音频和视频分别调整，范围为 `1` 至 `1024` MiB。Markdown 使用文本上限。默认上限为文本和 Markdown `5` MiB，PDF、图片、音频和视频 `100` MiB。各类型的预览行为和限制见[文件预览说明](文件预览.md)。

数值输入需在对应范围内才会保存；每个有效值修改后立即生效，预览会按新的上限执行。

## 文件传输并发

“同时传输文件数”控制单个上传或下载任务内部并行处理的文件数，默认值为 `4`，范围为 `1` 至 `16`。设置在任务开始时读取；修改后对之后开始的任务生效，当前任务使用原有并发数。同一服务器配置的传输任务仍按队列顺序执行。

## 性能监控

采样间隔默认 `3` 秒，可设置为 `1` 至 `300` 秒之间的整数。修改间隔后，活动监控会按新间隔重新安排后续采样。

可分别设置 CPU、内存、根分区使用率和每核 1 分钟系统负载的“注意”与“严重”界限。每项注意值必须小于严重值，范围为 `0` 至 `100`；前三项单位为百分比，系统负载按逻辑 CPU 数归一。默认值为 CPU/内存 `75% / 90%`、根分区 `80% / 90%`、每核负载 `1 / 2`。达到界限时，右上角摘要和详情会改变状态颜色，不发送弹窗通知。

## 启动与本机偏好

应用同一时间只运行一个实例。如果再次启动，已有窗口会显示并获得焦点；窗口最小化时会先还原。

最近成功连接的时间保存在本机并用于服务器列表排序。正式安装时，应用设置、窗口存储、缓存、日志、崩溃转储和临时文件保存在 `%APPDATA%\linux-nexus\`，开发运行时保存在项目目录的 `data/` 下。主题、默认文件视图、文件类型分类、预览大小上限、传输并发数、性能采样间隔与阈值、启动连接保存在其中的 `settings.json`；服务器配置、命令别名缓存和密码存储方式见[服务器连接与安全](服务器连接与安全.md)。搜索历史按服务器保存在本机，只包含搜索条件；详情见[文件搜索说明](文件搜索.md)。

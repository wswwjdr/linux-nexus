# 应用设置

点击窗口顶部的设置按钮可打开应用设置。设置保存后立即应用，并在下次启动时继续使用。

## 默认文件视图

默认文件视图可选择“图标视图”或“详细信息”。首次使用时默认是详细信息视图。此项设置决定启动后浏览文件时采用的视图；浏览过程中也可在路径栏临时切换。

## 启动时连接

可选择一个已保存的服务器，并设置启动后打开 SFTP 文件管理或 SSH 终端。不选择服务器时，应用启动后进入首页且不连接服务器。启动连接会使用已保存的 SSH 密码，并遵循主机指纹确认流程。

## 命令别名

命令别名按服务器连接分别管理。选择服务器后可同步或重新同步该账号 Bash 交互环境中实际生效的 alias；同步状态和最近成功同步时间保存在本机的 `servers.json` 中。服务器地址、端口或用户名变更后，该连接的别名缓存会清除。

新增别名需要填写名称和实际命令。同名别名会要求确认覆盖。新增、覆盖和删除会修改服务器用户目录中的 `~/.bashrc`；删除和覆盖只在文件中存在唯一、整行完全匹配的单行定义时进行，否则应用会拒绝修改以避免误删或误改。若别名来自其他配置文件，应用会显示无法安全删除的原因。

别名功能首版仅支持 Bash。服务器操作使用已保存的连接凭据并遵循主机指纹确认流程。变更会在之后新开的 SSH 终端中生效，已打开终端不会自动重载配置。

## 预览大小上限

设置中可分别调整文本、图片、音频和视频的预览上限。每项须为 `1` 至 `1024` MiB 之间的整数。各类型默认值、超限提示和可预览格式见[文件预览说明](文件预览.md)。

设置无效时无法保存，应用会显示错误；保存成功后，预览会按新的上限执行。

## 启动与本机偏好

应用同一时间只运行一个实例。如果再次启动，已有窗口会显示并获得焦点；窗口最小化时会先还原。

默认文件视图保存在本机应用偏好中，最近成功连接的时间也会保存在本机并用于服务器列表排序。正式安装时，应用设置、窗口存储、缓存、日志、崩溃转储和临时文件保存在 `%APPDATA%\linux-nexus\`，开发运行时保存在项目目录的 `data/` 下。预览大小上限和启动连接保存在其中的 `settings.json`；服务器配置、命令别名缓存和密码存储方式见[服务器连接与安全](服务器连接与安全.md)。搜索历史按服务器保存在本机，只包含搜索条件；详情见[文件搜索说明](文件搜索.md)。

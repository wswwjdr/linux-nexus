# 服务器连接与安全

Linux Nexus 使用 SSH 建立终端和文件管理会话。文件管理器通过 SSH 命令通道调用 Linux 原生命令，不会在服务器安装常驻助手。

## 管理服务器

未连接时，主区域显示已保存的服务器。添加服务器时填写连接名称、主机、端口、用户名和 SSH 密码。端口默认为 `22`，有效范围是 `1` 至 `65535`。密码由 Windows 凭据能力加密保存；密码框留空编辑配置时会保留已保存的密码。

## 连接和能力要求

文件会话按 Linux 服务器实际提供的命令能力准入。连接时使用 `/bin/sh` 检查 Bash 及目录浏览所需的 `find` 选项。下载、预览、搜索、写入、属性和解压各自检查所需工具。SSH 终端保持服务器原生交互。

包管理适配与文件会话准入独立。应用把 `os-release` 当作数据读取，以发行版身份及衍生关系辅助识别 apt-get、dnf 或 yum，并验证管理器可以执行。已知缺失能力能唯一映射到软件包时，弹窗列出包管理器和软件包，确认后使用服务器现有软件源安装，必要时请求 sudo 密码。重新检查通过后才进入文件管理或继续操作。工具已存在但不兼容、包管理器无法识别等情况，可以手动准备后重新检查。

首次进入文件管理时，解压工具不齐会显示受影响的格式，可以安装，也可以跳过。成功加载目录后记住选择。地址、端口、账号或主机指纹变化后重新检查。实际解压时只检查所选格式，例如 ZIP 使用 `unzip`，压缩 tar 需要 `tar` 和对应的压缩工具。各发行版的实机验证见[待处理](待处理.md)。

文件会话只对普通文件和目录执行复制、移动、重命名、删除、上传、下载和解压。符号链接、设备、管道和套接字可在列表中查看，但不能作为操作对象。重命名仅在原目录内进行，不覆盖已存在的同名文件、目录或符号链接，也不能重命名服务器根目录。

## 文件会话的 sudo

root 模式要求服务器允许 SSH 登录账号通过非交互式 sudo 以 root 执行 Bash。支持免密授权和单次密码提示。要求真实 TTY 或多步认证的策略可在 SSH 终端中使用。sudo 密码仅保留在当前文件会话的主进程内存中，退出 root 模式、认证失效或断线时清除。

从已提权的文件会话打开 SSH 终端时，应用使用该会话的 sudo 认证信息启动 root Shell，并从文件管理器的当前目录进入。终端建立后独立运行，可以用 `exit` 结束。重连或复制该终端时，来源文件会话需要处于 root 模式。

## SSH 主机指纹

首次连接会显示服务器 SHA-256 主机指纹。请核对指纹后再选择信任。若保存的指纹与服务器当前指纹不同，连接会暂停并同时显示两者；确认变化原因后再信任新指纹。

## 本机数据

服务器配置、加密密码、主机指纹、命令别名缓存和应用设置保存在 `%APPDATA%\linux-nexus`。会话内容和传输任务只在应用运行期间保留。

命令别名仅支持 Bash 登录 Shell。覆盖和删除在图形确认后直接执行服务器修改命令；命令会要求 `.bashrc` 是普通文件，并只修改唯一且整行匹配的定义。更新采用同目录临时文件和原子替换，保留原文件权限；目标定义变化或不符合修改条件时，服务器返回错误并停止操作。

应用主界面使用 CSP、进程隔离和沙箱；禁止页面导航与新窗口，特权 IPC 只接受应用主窗口的主 frame。未授权网页权限默认拒绝。

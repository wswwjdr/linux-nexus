# 服务器连接与安全

Linux Nexus 通过 SSH 建立连接，并使用 SFTP 浏览和传输文件。服务器连接配置保存在本机；应用不会把 SSH 密码以明文形式保存。

## 管理服务器

未连接时，主区域显示已保存的服务器。点击“添加服务器”填写连接名称、主机地址、端口、用户名和 SSH 密码。端口默认是 `22`，有效范围为 `1` 至 `65535`。

点击已有服务器可发起连接。点击条目旁的图钉可置顶或取消置顶；置顶服务器排在列表前面，同一分组内按最近成功连接的时间排序，尚未连接过的服务器排在后面。通过服务器条目旁的编辑按钮修改配置。编辑时密码框留空会保留当前保存的密码；填写新密码则更新密码。删除连接配置前会要求确认。

## 连接与断开

连接成功后会从服务器根目录 `/` 开始浏览。窗口顶部会显示当前连接的用户名和主机；点击“断开”结束连接并返回服务器列表。应用同一时间只连接一台服务器；断开后可从服务器列表选择其他服务器，切换时当前 SSH 会话会关闭。

如果认证失败、服务器不可达或服务器没有提供 SFTP，应用会显示连接错误。检查主机地址、端口、用户名和密码，以及网络或 VPN 状态；SFTP 不可用时需要服务器端启用 SFTP 服务。

## SSH 主机指纹

首次连接某台服务器时，应用会显示服务器的 SHA-256 主机指纹。请先与服务器管理员提供的指纹核对，再选择信任并继续连接。确认后，应用会记住该指纹，后续连接会自动核对。

如果已保存的指纹与当前服务器不同，应用会同时显示原指纹和新指纹，并暂停连接。指纹变化可能有正常原因，也可能表示连接到了另一台主机；确认变化原因并核对新指纹后再信任。关闭提示不会建立连接。

## 本机保存的数据

服务器连接配置、已加密的 SSH 密码、已确认的主机指纹和按连接隔离的命令别名缓存保存在 `%APPDATA%\linux-nexus\servers.json`。密码由 Windows 凭据加密能力保护；如果加密能力不可用，应用不会读取保存的密码。应用设置保存在同一目录的 `settings.json`。

命令别名同步仅支持 Bash 登录 Shell，并从交互式 Bash 环境读取当前生效的 alias。新增别名会写入 `~/.bashrc`。覆盖或删除时，应用只接受唯一且整行完全匹配的单行定义；若别名来自 `~/.bash_aliases`、系统配置、其他文件，或 `.bashrc` 中的定义不唯一/格式不同，应用不会修改文件。文件修改通过同目录临时文件和原子替换完成，并保留原文件权限。变更仅对之后新开的 SSH 终端生效。

启动时应用会检查服务器配置、命令别名缓存和应用设置文件。如果文件格式或数据结构无效，应用会显示出错文件路径并停止启动，不会自动重置或覆盖文件。旧版服务器配置会按尚未同步处理。保存配置失败时会显示错误。

# 服务器连接与安全

Linux Nexus 使用 SSH 建立终端和文件管理会话。文件管理器通过 SSH 命令通道调用 Linux 原生命令，不会在服务器安装常驻助手。

## 管理服务器

未连接时，主区域显示已保存的服务器。添加服务器时填写连接名称、主机、端口、用户名和 SSH 密码。端口默认为 `22`，有效范围是 `1` 至 `65535`。密码由 Windows 凭据能力加密保存；密码框留空编辑配置时会保留已保存的密码。

## 连接和能力要求

文件会话支持 Ubuntu、Debian、CentOS 7/8、CentOS Stream 8/9/10 和 RHEL 8/9/10。Ubuntu、Debian 不限制版本号，但仍需通过基础命令检查；其他发行版不按衍生关系自动放行。SSH 终端会话不受此发行版清单限制。

文件会话要求服务器提供 Bash、GNU coreutils、GNU findutils、GNU grep、GNU tar 和 sed。使用的命令包括 cat、cp、mv、rm、mkdir、rmdir、find、grep、tar、sha256sum、dd、tail、head、mktemp、stat、touch、chmod、readlink、du、base64、dirname、basename 和 sed。连接时，应用将 `/etc/os-release` 作为数据读取并检查 `ID`、`VERSION_ID`，不会执行该文件内容；随后检查基础命令、GNU 工具以及 dd 字节读取和 tar 解压策略选项。检查失败时不激活文件会话，并显示错误。

服务器需要预先安装所用归档格式对应的解压工具，例如 unzip、gzip、bzip2、xz 或 zstd。工具缺失时，服务器解压命令会失败并显示原始 stderr；应用不会检测或安装依赖。

文件会话只对普通文件和目录执行复制、移动、重命名、删除、上传、下载和解压。符号链接、设备、管道和套接字可在列表中查看，但不能作为操作对象。重命名仅在原目录内进行，不覆盖已存在的同名文件、目录或符号链接，也不能重命名服务器根目录。

## SSH 主机指纹

首次连接会显示服务器 SHA-256 主机指纹。请核对指纹后再选择信任。若保存的指纹与服务器当前指纹不同，连接会暂停并同时显示两者；确认变化原因后再信任新指纹。

## 本机数据

服务器配置、加密密码、主机指纹、命令别名缓存和应用设置保存在 `%APPDATA%\linux-nexus`。会话内容和传输任务只在应用运行期间保留。

命令别名仅支持 Bash 登录 Shell。覆盖和删除在图形确认后直接执行服务器修改命令；命令会要求 `.bashrc` 是普通文件，并只修改唯一且整行匹配的定义。更新采用同目录临时文件和原子替换，保留原文件权限；目标定义变化或不符合修改条件时，服务器返回错误并停止操作。

应用主界面使用 CSP、进程隔离和沙箱；禁止页面导航与新窗口，特权 IPC 只接受应用主窗口的主 frame。未授权网页权限默认拒绝。

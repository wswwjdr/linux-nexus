## 标题
Linux Nexus v0.1.0

## 发版说明

### Linux Nexus 首个版本

Linux Nexus 是一款用于通过 SSH/SFTP 管理 linux 服务器文件的 客户端。

### 功能

- 管理服务器连接，并在首次连接时核对 SSH 主机指纹
- 同时使用多个 SFTP 文件管理和 SSH 终端会话
- 浏览远端文件，进行搜索、预览、复制、移动、上传和下载
- 查看传输进度，并取消进行中的任务
- 预览和编辑文本文件，查看 Markdown、PDF 和图片，播放音频与视频
- 保存常用 Bash 命令别名，并设置启动连接、外观和文件预览选项

### 安装

下载 Windows x64 安装包（`.exe`）并运行。

### 说明

当前主要面向 Ubuntu/Linux OpenSSH。其他 SFTP 服务端的兼容性尚未完整验证。音视频播放能力取决于当前 Chromium 支持的格式。

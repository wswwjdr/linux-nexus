# 远端脚本执行

文件列表和文件搜索结果中的脚本类型文件可直接执行，也可先调整命令再执行。可用文件类型和后缀由[应用设置](应用设置.md)中的脚本分类决定。

## 执行方式

脚本通过当前 SFTP 会话对应的 SSH 连接，在服务器上执行，不会先下载到本机。默认命令为 `./文件名`，执行时的当前目录是脚本所在目录。例如，直接执行 `deploy.sh` 时会运行 `./deploy.sh`。

默认命令要求服务器能够直接执行该文件；通常需要执行权限，带有 shebang 时由其中指定的解释器处理。需要显式指定解释器时，可使用“调整命令后执行”，例如输入 `python3 ./task.py` 或 `sh ./deploy.sh`。调整后的命令会交给远端 `sh -c` 执行，并以 SSH 用户身份运行；命令可访问该用户权限范围内的文件和程序。执行前请确认命令内容及其对服务器的影响。

## 输出与停止

执行窗口会持续显示标准输出和错误输出，并显示运行、完成、停止或失败状态。正常退出码为 `0` 时显示完成；非零退出码或 SSH 通道错误会显示失败原因。

点击“停止执行”或在执行过程中关闭窗口，应用会向远端执行通道发送 `TERM` 并关闭通道。远端命令及其启动的后台进程如何响应由服务器处理；停止执行不会撤销脚本已完成的操作。

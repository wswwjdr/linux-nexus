# 远端脚本执行

脚本通过当前文件会话的 SSH 连接在服务器执行，不会先下载到 Windows。默认命令为 `./文件名`，工作目录是脚本所在目录。可在执行前调整命令。

脚本运行状态和 stdout、stderr 会显示在应用内；执行期间可取消，应用向服务器命令发送 `TERM`。脚本以当前 SSH 登录用户身份运行，不会自动使用 sudo。执行结果取决于该用户的权限、服务器 Shell 和脚本自身行为。

stdout 和 stderr 合计上限为 8 MiB，达到上限后保留已显示输出，明确报告限制并停止读取、请求终止；不静默丢弃。取消请求 TERM 后最多等待 2 秒，界面区分等待取消与取消结果，并提示远端及子进程状态未确认。关闭通道不构成回滚或进程树终止保证。

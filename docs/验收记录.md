# 验收记录

最初审查整改日期：2026-10-29；最近更新：2026-11-01（预览组件复刻）。此记录区分本机自动验证与真实服务器验证；新增 CI 配置不代表 CI 已运行成功。

## 本轮实现

- 复制／移动固定目录目标，并在同一条服务器命令内校验顶层来源类型。
- 下载拒绝无法映射的 Windows 文件名；目录独占预留，文件使用不覆盖硬链接发布，提交时冲突继续编号。不支持硬链接的目标文件系统明确失败。
- 文本编辑保留 UTF-8／GBK 编码及 UTF-8 BOM，显式转换编码；保存比较 SHA-256 与文件身份，冲突保留草稿并要求再次明确强制覆盖。
- 写入需要完整字节和 SHA-256 提交记录，拒绝异常 EOF。在线编辑在提交前保全并核验所有权、权限、ACL、扩展属性，拒绝多硬链接文件。
- 统一 SSH 命令生命周期、连接级任务归属、输出背压、超时与取消；关闭会话和退出应用会等待本机任务结束。远端进程树状态不提供保证。
- 文件列表及内容结果虚拟渲染；文件树按记录增量解析并对消费者施加背压。搜索协议输出上限 32 MiB、文件树协议 128 MiB、脚本输出 8 MiB、通用 stderr 保留 256 KiB 并标注截断。
- CSP、导航／重定向／新窗口限制、网页权限限制及 IPC 主 frame 校验；删除旧数据迁移和旧结构兼容分支。
- 音视频、图片和 Markdown 使用独立的会话内预览组件；音视频共用标题栏、快捷键帮助和基础播放控制。视频使用 Video.js 8.23.7，不保存历史播放进度；图片支持拖拽、缩放、旋转和翻转；Markdown 提供只读目录、离线代码高亮与复制。
- Markdown 图片支持当前服务器路径和 HTTP/HTTPS 地址；服务器资源绑定文档 token、会话及服务器配置，关闭后撤销访问并终止流。CSP 允许网络图片，不放宽脚本、导航或文件读取权限。

## 已执行验证

2026-11-01 本机最终完整测试：206 项，203 通过、0 失败、3 跳过。跳过项为仅 Linux 的内容搜索脚本测试、POSIX 悬空符号链接测试、需要 acl／attr 的真实元数据测试；没有把跳过计为通过。下列 Chromium／Electron 交互验证在本机 Electron 44.10.0 中执行，不代表 Windows 安装包或真实服务器验收。

- 类型检查及生产构建。
- 临时目录中实际执行生成的复制／移动命令，验证目标消失或变成文件时拒绝执行。
- 并发下载提交测试：保留原文件，四个竞争写入各自生成完整编号副本。
- 编码往返及在线编辑交互测试：GBK、UTF-8 BOM、有损保存拒绝、冲突草稿保留、强制覆盖及版本更新。
- 命令生命周期测试：通道打开前超时、迟到通道释放、16 个命令共享连接观察者、断网失败、无退出确认的取消。
- Chromium 虚拟滚动测试：1 万项目录的详细视图和图标视图，DOM 数量受限且可以滚动到最后一项；已检查截图。
- 合成 SSH 流测试：10 万文件树，独立运行约 993 ms，采样堆增长约 55 MiB（包含解析器与模拟传输分配）；这不是实际网络吞吐或完整下载任务的性能承诺。
- 元数据读取失败时原文件保留、临时文件清理的服务器脚本测试。
- 音频使用真实 WAV 验证播放、原生进度条拖动、快捷键、切换会话暂停及重新打开重置；深浅主题与不同窗口尺寸共检查 12 组布局。
- 视频使用合成 WebM 和实际 `remote-preview` 协议验证播放、进度条拖动、全屏、两级 Esc、长按临时倍速与恢复、会话暂停，以及自动播放受阻后的手动恢复；视频、图片、Markdown 共检查 12 组深浅主题及小窗口布局，并检查截图。
- 图片适配比例、旋转边界、缩放锚点和上下限测试，以及 Electron 中真实指针拖拽、旋转翻转、适应窗口交互。
- Markdown GFM、离线高亮、原文代码复制、目录跳转、阅读位置保留、重复标题锚点及图片局部错误测试；切换目录不重建正文图片和代码块。
- 模拟 SSH 验证 Markdown 图片路径解码、中文及空格路径、Range、类型与大小限制、权限失败、失效会话、关闭文档时中止读取。没有使用真实 SSH 服务器验证这些资源请求。

## 一致性边界

SHA-256 校验后到改名之间仍存在外部写入竞态；没有远端助手或协作锁时，不承诺跨程序严格原子比较替换。取消、超时及连接中断不意味着回滚，也不能证明远端全部子进程已退出。提交附近断连应重新读取目标确认实际结果。文件原子发布不等于断电持久性保证。

# 文件搜索

文件搜索面向当前已连接的服务器，提供“文件名”和“文本内容”两个独立搜索页。两页分别保存搜索条件、历史、进度和结果；它们在远端通过 SSH `exec` 调用 GNU `find`，SFTP 仍用于文件浏览与传输。

## 打开与范围

连接服务器并进入文件浏览视图后，点击顶部搜索按钮，或按 `Ctrl+F` 打开搜索窗口。每个搜索页都可以选择：

- **当前目录**：搜索打开窗口时所在的远端目录及其子目录。
- **系统根目录**：从 `/` 开始搜索，包括系统目录和挂载文件系统，语义与 `find /` 一致。
- **自定义**：输入规范化的绝对远端路径，例如 `/var/www`；路径必须以 `/` 开头，且不能含 `.` 或 `..` 路径段。

范围路径必须存在且可访问。搜索会继续处理有权限读取的位置，并在错误提示中标明结果可能不完整。

## 文件名搜索

文件名搜索只匹配普通文件的名称，不匹配目录、符号链接或完整路径。精确模式对应远端命令 `find <范围> -type f -iname/-name <文件名> -print0`；名称包含模式使用相同命令并将字面查询包成 `*查询*`。查询中的 `*`、`?`、`[`、`]` 和反斜杠均按普通字符处理。默认忽略大小写，取消“忽略大小写”后区分大小写。

结果按远端输出流式显示，不限制命中数量；长结果列表使用虚拟滚动。列表显示命中文件数、耗时和当前扫描状态。权限或遍历错误会保留已找到的结果，并提示结果可能不完整。

## 文本内容搜索

文本内容搜索使用 GNU `find` 单遍遍历普通文件，按文件大小筛选后每批最多将 64 个路径交给 GNU `grep -F -H -n -C 1 -Z` 检查，不为了百分比再次盘点。默认忽略大小写；取消“忽略大小写”后区分大小写。命中按文件归组显示命中行、行号及相邻上下文。使用 NUL 分隔的路径输入和 grep 文件名输出，文件名含空格、换行等字符时仍可正确处理。

默认跳过大于 100 MiB 的文件；可将上限设为 1 至 102400 MiB 之间的整数。GNU `grep` 会忽略二进制匹配内容；界面会分别显示因大小限制跳过的文件、被识别为二进制匹配的文件和读取错误。进度显示已扫描文件数、字节数、命中数量、耗时、速率和当前路径，不执行预盘点，也不计算百分比或 ETA。

## 结果操作与历史

点击结果可打开操作菜单，按文件类型提供预览、倒序预览、脚本操作和打开所在目录等现有能力。搜索进行时切换标签会保留该页的运行状态；关闭窗口会先询问是否取消正在运行的搜索。

文件名和文本内容搜索分别在本机保存最近 10 次条件。历史只包含查询和搜索条件，不包含命中的远端路径或文本内容。点击历史项只会恢复条件，不会自动开始搜索；清空操作只影响当前搜索页的历史。

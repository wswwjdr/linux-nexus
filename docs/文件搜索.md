# 文件搜索

搜索针对当前 SSH 文件会话所连接的服务器，包含文件名和文本内容两个页面。搜索由服务器执行，不会先下载目录或文件内容到 Windows。

文件名搜索调用 GNU `find`，文本搜索调用服务器端 `grep`。可设置起始目录、名称或内容条件，并查看搜索进度和匹配结果。每个搜索页分别保存条件、历史和结果；取消操作会停止对应服务器命令。

结果可打开所在目录，也可使用适用的预览和脚本操作。搜索能力取决于服务器 Bash、findutils、grep 和用户对目标目录的读取权限。

文件名与内容搜索分别限制为 32 MiB 远端协议输出，单条名称记录最多 1 MiB、内容记录最多 2 MiB；超限会保留已收到结果并明确失败／标记不完整，不静默截断。结果采用虚拟渲染，内容结果卡片内可滚动查看匹配。取消会请求远端 TERM；命令通道结束也不能证明所有子进程退出，界面提示远端状态未确认。长任务上限 24 小时。

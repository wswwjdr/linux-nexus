# 文件传输

上传和下载通过 SSH 命令通道传输必要的文件字节。远端目录创建、目标检查和文件替换由服务器命令执行。

## 上传

- 顶部“上传文件”可选择多个本机文件；“上传文件夹”会保留文件夹名、目录结构和空目录。
- 在文件列表空白处右键可按策略选择上传；也可将本机文件或文件夹拖入列表。
- 选择后，应用在主进程收集本机文件清单，不检查服务器目标。确认弹窗提供强制覆盖 `-f`、跳过 `-n`、仅较新源文件更新 `-u` 和确认后处理策略；“确认后处理”会让用户选择遇到同名目标时全部覆盖或全部跳过。
- 文件内容通过 SSH stdin 写入服务器同目录临时文件，完整后由服务器 `mv` 原子替换。覆盖、跳过和更新分别使用 `mv -fT`、`mv -nT` 与 `mv -uT`。取消或失败时临时文件会清理，原目标不会被部分内容覆盖。

符号链接和特殊文件不能上传。文件夹中无法读取的项目会列入本机文件清单错误；其余可上传项目仍可确认执行。文件夹上传会在服务器合并已存在目录。目标路径错误或权限不足时由服务器命令返回错误。Linux 权限不会从 Windows 伪造。

## 下载

右键远端文件或文件夹可下载；多选后可以一次下载多个项目。服务器通过 SSH 命令读取文件字节，Windows 选择下载目录并负责写入本机文件。若本机存在同名项目，应用自动生成“名称 (1).扩展名”等编号名称，不弹出覆盖对话框。

下载服务器根目录 `/` 不受支持。符号链接、设备和无法由 Windows 表示的名称不能下载。下载期间写入本机临时文件，完整后再改名；取消或失败时临时文件会清理。

## 远端复制与移动

复制和移动由服务器 `cp` 与 `mv` 完成，文件内容不经过 Windows。按 `Ctrl+C` / `Ctrl+X` 记录远端来源，切换到目标目录后按 `Ctrl+V` 直接按强制覆盖策略粘贴；命令发送前仍会显示操作确认弹窗。右键粘贴可选择其他操作策略，目录拖放移动也会显示确认并运行服务器命令。详细策略与取消行为见[文件浏览与操作](文件浏览与操作.md)。

## 进度与取消

传输区域显示上传和下载任务的字节进度、文件计数和状态。进行中的传输可取消；已完成文件保留，当前文件的服务器或本机临时文件会清理。相同服务器配置的传输任务排队，等待中的任务可取消；并发数可在[应用设置](应用设置.md)调整。

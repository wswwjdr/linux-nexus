# 文件传输

上传和下载通过 SSH 命令通道传输必要的文件字节。远端目录创建、目标检查和文件替换由服务器命令执行。

## 上传

- 顶部“上传文件”可选择多个本机文件；“上传文件夹”会保留文件夹名、目录结构和空目录。
- 在文件列表空白处右键可按策略选择上传；也可将本机文件或文件夹拖入列表。
- 可通过菜单选择强制覆盖 `-f`、跳过 `-n`、仅较新源文件更新 `-u` 或确认后处理策略。主进程收集本机清单；“确认后处理”会通过一次 SSH 命令扫描目标冲突，有冲突才显示全部覆盖／全部跳过确认，无冲突时使用跳过策略执行。扫描不构成目标预留，最终行为以执行时的服务器状态为准。
- 文件内容通过 SSH stdin 写入目标所在目录下的私有暂存目录，目录名为 `.原文件名.uploading`（例如 `.音乐专辑.mp4.uploading`），通过独占创建防止同名上传共用暂存目录；同名暂存路径已存在时本次文件上传失败，不复用或清理已有路径。检查来源未变化、接收完整字节及 SHA-256 提交记录后，由服务器 `mv` 原子替换。覆盖、跳过和更新分别使用 `mv -fT`、`mv -nT` 与 `mv -uT`。成功、失败或取消都会尝试清理暂存文件和目录；异常 EOF 或校验失败不允许提交。提交点附近取消或连接中断时结果可能未知，应刷新确认；已提交的目标不会回滚。
- 新文件遵循远端普通文件创建规则：没有默认 ACL 时，权限为 `0666` 经远端命令进程的 `umask` 限制（例如 `022` 得到 `644`）；有默认 ACL 时按服务器文件系统规则继承。覆盖已有普通文件会保留目标的权限位和访问 ACL；权限复制失败则不替换目标。上传保留本机文件的修改时间。新建目录继续遵循远端 `mkdir -p` 规则，已有目录不改变权限。

符号链接和特殊文件不能上传。文件夹中无法读取的项目会列入本机文件清单错误；其余可上传项目仍可确认执行。文件夹上传会在服务器合并已存在目录。目标路径错误或权限不足时由服务器命令返回错误。Linux 权限不会从 Windows 伪造。

## 下载

右键远端文件或文件夹可下载；多选后可以一次下载多个项目。服务器通过 SSH 命令读取文件字节，Windows 选择下载目录并负责写入本机文件。若本机存在同名项目，应用自动生成“名称 (1).扩展名”等编号名称，不弹出覆盖对话框。

下载服务器根目录 `/` 不受支持。符号链接、设备和无法由 Windows 表示的名称不能下载。下载期间写入同目录临时文件，完整后通过硬链接独占发布最终名称，不覆盖已有文件；提交时发生重名会继续编号。文件夹名称使用独占 mkdir 预留；取消后可能保留已创建的空目录。源文件名中的反斜杠会被拒绝，不转换成 Windows 子目录。下载位置必须支持硬链接（如 NTFS）；不支持时明确失败，不降级为可覆盖的改名。当前文件临时文件会尽力清理，已完成文件保留。

## 远端复制与移动

复制和移动由服务器 `cp` 与 `mv` 完成，文件内容不经过 Windows。按 `Ctrl+C` / `Ctrl+X` 记录远端来源，切换到目标目录后按 `Ctrl+V` 直接按强制覆盖策略粘贴；不显示执行确认或命令预览弹窗。右键粘贴只提供覆盖和跳过，选择即执行；拖动时记录来源，放到目标文件夹后直接执行 `mv -f`。移动不合并同名非空文件夹，相关错误由服务器返回。详细策略与取消行为见[文件浏览与操作](文件浏览与操作.md)。

## 进度与取消

传输区域显示上传和下载任务的字节进度、文件计数和状态。进行中的传输可取消；已完成文件保留，当前文件的服务器或本机临时文件会清理。相同服务器配置的传输任务排队，等待中的任务可取消；并发数可在[应用设置](应用设置.md)调整。

## 执行限制

普通元数据命令默认 30 秒超时，传输与长任务上限为 24 小时。取消会请求 TERM，最多等待 2 秒后停止本机等待；界面明确提示远端状态未确认。取消不等于回滚，断网时远端临时文件可能残留。

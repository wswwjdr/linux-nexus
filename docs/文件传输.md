# 文件传输

连接服务器后，可将本机文件上传到当前远端目录，也可将远端文件或文件夹下载到本机。传输中的任务会显示在窗口底部。

## 上传

- 点击顶部“上传文件”，在文件选择窗口中可一次选择多个文件。
- 在文件列表空白处打开右键菜单并选择“上传”，也可选择一个或多个本机文件。
- 点击顶部“上传文件夹”，选择一个本机文件夹。文件夹会连同其中内容上传到当前远端目录下，并保留所选文件夹的名称。
- 将本机文件或文件夹拖到文件列表中也可上传；落在列表条目或空白处都会上传到当前远端目录。文件夹会保留名称、目录结构和空文件夹。

上传只接受普通文件和文件夹，不支持上传符号链接。若远端已有同名文件，应用会先询问是否覆盖；同名文件夹会合并。取消确认会放弃本次传输。

## 下载

在远端文件或文件夹上打开右键菜单，选择“下载文件”或“下载文件夹”，然后选择本机保存位置。下载文件夹会在所选位置下创建同名文件夹，并递归下载其内容。

下载会先检查本机是否存在同名文件。存在时应用会询问是否覆盖；同名文件夹会合并。服务器根目录 `/` 暂不支持下载，符号链接也不支持下载。无法由 Windows 文件系统表示的名称会导致下载失败并显示错误。

每个文件先在安装目录的 `data/temp/` 中暂存，再重命名为最终文件。若下载目标与安装目录不在同一磁盘，应用会先在目标目录旁创建过渡文件再重命名，以确保下载失败时不会留下不完整的目标文件，并在确认覆盖后一次性替换旧文件。

## 进度与取消

传输区域显示当前进度和任务状态。传输进行中可点击取消；取消后不会继续处理后续文件，已完整传输的文件会保留，未完成文件的临时数据会清理。完成或取消状态可关闭隐藏，并会在短暂显示后自动消失。

同一台服务器同时只能执行一个文件传输任务。连接中断或本机、服务器路径不可用时，传输会失败并显示错误；上传后应用会刷新当前目录。
